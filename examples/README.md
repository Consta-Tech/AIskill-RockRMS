# Examples

Ready-to-copy starting points for extending the AIskill-RockRMS ecosystem.

| Directory | What it is |
|---|---|
| [overlay-template/](overlay-template/) | Skeleton for a church-specific overlay plugin — copy it, rename the placeholders, and publish it (typically private) in your church's own GitHub org. |

Nothing in this directory is loaded by the `rockrms` plugin itself — these are templates for humans to copy.
